# Design references

`reference/` is a byte-for-byte snapshot of the supplied MediTrack project sources, copied so the repository works independently of its original ChatGPT project folder. It includes the interactive `index.html`, requirements, design tokens, accessibility reports and original helper scripts.

The upstream synced files were not moved or edited. One project source could not be synced and is not represented here. These files are reference material, not Flutter build inputs; the Flutter app and verification scripts do not execute the reference helper scripts.

Use `reference/index.html` as the primary visual reference. Consult `DESIGN_PARITY.md` for the mapping and intentional adaptations. `source-checksums.sha256` records the copied file contents at repository preparation time.
